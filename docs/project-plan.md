# Project Scope

Our program covers the following:

## Algorithms

The program will cover the following algorithms:

- Mergesort
- Quicksort
- Shacker Sort
- Heapsort

## Execution Criteria

Each execution will cover the following criteria:

- Measurement of:
  - A count of time to run
  - Proof of the number of comparisons
- An output that can be passed to a reporting class that provides an aggregated description of performance.
